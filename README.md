# DeepSeek 对话导出

一键导出 DeepSeek 对话内容为 Markdown 格式，自动区分用户输入和 AI 回答。

## 功能特点

① **精准识别**：自动识别对话框的复制按钮，排除代码块、图片等其他内容的干扰；

② **区分角色**：自动区分用户输入（👤）和 AI 回答（🤖），并在导出时清晰标注；

③ **实时进度**：显示提取进度和当前处理的消息类型，过程可视化；

④ **格式规范**：导出的 Markdown 文件包含时间戳、对话轮数统计和清晰的分隔符。

## 注意事项

- 请确保页面完全加载后再点击导出按钮
- 提取过程中请勿刷新页面或切换对话
- 脚本通过拦截复制接口获取原始 Markdown 格式数据，不会真正写入系统剪贴板

## 技术原理

脚本通过以下方式工作：

1. **按钮识别**：分析按钮组结构，用户输入框有 2 个按钮（复制、编辑），AI 回答框有 5 个按钮（复制、重新生成、点赞、点踩、分享）
2. **数据拦截**：临时覆盖 `navigator.clipboard.writeText` 方法，截获网页写入的原始数据
3. **顺序处理**：按页面顺序依次点击复制按钮，确保对话顺序正确
4. **格式化输出**：将截获的数据整理成规范的 Markdown 格式并下载
